# Property Portal

Property Portal is a web-first marketplace for buying, selling, and renting real estate in Myanmar. The initial release targets Yangon and Mandalay, with a location model ready for future cities and neighborhoods.

## Projects

- [API](api/README.md) — Express, Prisma, SQLite backend.
- [Web app](app/README.md) — React/Vite browser experience.
- [Mobile app](mobile/README.md) — Expo application for the later phase.
